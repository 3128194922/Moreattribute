# 最大经验等级属性设计

## 目标

为 `Moreattribute` 增加玩家属性“最大经验等级”，范围为 0 至 `Integer.MAX_VALUE`，默认值为 0。属性值为 0 时不限制经验等级；属性值大于 0 时，原版经验增长不能使玩家等级超过该属性的整数部分。到达启用的上限后，玩家不能继续吸收经验球。

## 设计

### 属性

- 在现有 `ModAttributes` 中注册 `max_experience_level`，作为玩家属性加入玩家属性集合，并设为可同步。
- 默认值为 0，范围为 0 至 2147483647；0 表示无上限，正数读取时向下取整为等级上限。
- 在 `zh_cn.json` 中增加对应的“最大经验等级”名称。
- 属性变化通过原版属性修饰器生效，不新增配置项或依赖。

### 经验限制

- 新增 Forge 游戏事件处理器，检查玩家当前的最大经验等级属性。
- 属性值为 0 时，不限制经验点、等级变化或经验球拾取，保持原版行为。属性为正数时向下取整作为等级上限；例如 0.5 的有效上限为 0 级。
- 属性值大于 0 时，对 `PlayerXpEvent.XpChange` 限制正向经验点增长：若本次增长会越过上限，只允许增长到上限所需的经验；超出部分不保留。经验阈值使用任意精度整数计算，避免上限接近 `Integer.MAX_VALUE` 时溢出。
- 属性值大于 0 时，对 `PlayerXpEvent.LevelChange` 限制正向等级变化，避免原版等级增加入口越过上限。负向经验或等级变化照常执行。
- 属性值大于 0 时，对 `PlayerXpEvent.PickupXp` 执行上限检查：玩家当前等级已达到或超过上限时取消拾取；碰撞不会吸收经验球，经验球留在世界中。使玩家刚好升到上限的经验球正常吸收，此后的经验球均不会被拾取。
- 若已启用的属性上限被调低，保留玩家已有等级；在等级再次低于上限前不允许吸收正向经验。
- 原版 `/experience`（别名 `/xp`）的 `add` 子命令通过上述经验事件受限；`set levels` 与 `set points` 通过服务端玩家经验设置入口执行额外检查。启用上限时，直接设置的等级不能超过上限；玩家已达到或超过上限时，直接设置经验条进度会被归零。
- 所有经验事件和服务端经验设置入口都将属性值 0 视为无限制，保留原版行为。

## 验收标准

1. 玩家默认属性为 0，经验获取保持原版行为，不设置等级上限。
2. 属性值为 0 时，不限制经验点增长、等级变化或经验球拾取。
3. 属性值大于 0 时，经验增长不会使等级超过该值向下取整后的上限；跨越上限的溢出部分不计入。
4. 玩家升到启用的属性上限后，经验球不会被玩家拾取或吸收，并留在世界中。
5. 通过原版等级增加入口无法越过启用的上限；负向经验变化仍可正常降低等级。
6. 原版 `/experience` 与 `/xp` 的 `set levels` 不会越过启用的上限；已达上限时 `set points` 不会留下经验进度。
7. 经验上限可由玩家属性修饰器改变，客户端能读取同步后的属性。
8. 现有工作区改动保持原样；中文语言资源仅追加新属性名称。
